## 改动

- BotsTab 改为按 `id+createdAt` 挂载的页内详情：概览、任务与消息、记忆、设置、历史。快速创建继续用原生 Modal。
- 列表直接显示资料入口，主操作仍打开聊天；详情返回保留搜索、滚动与触发按钮焦点。
- BotEditor 页内保存保留错误草稿；切页保留编辑状态，离开需确认；迟到保存只影响仍挂载的身份。工具编辑和任务补充也登记未保存状态。
- BotIdentity 共享列表和两种侧栏的头像/名称/摘要；同名显示稳定标识。使用原生 SegmentedTabs、Menu、Input、Toast，去除重复管理/创建入口。
