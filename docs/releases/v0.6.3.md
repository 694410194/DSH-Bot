# v0.6.3 社区首发 / First community release

本次将 U3/U4 汇总进入 main，首发准备使用独立发布分支。发布附件和最终摘要在 GitHub Release 上提供；公开前不把候选材料当作下载完成。

## 功能与边界

- Bot 页内资料、任务与消息、记忆、设置及历史，设置保持当前 Bot 上下文并可返回。
- 群成员并发、明确请求驱动的多轮工作、逐问题折叠过程、原生思考与只读执行详情、用户右/Bot 左。
- 通知记录与策略分区，导入预览/冲突校验、原生 JSON 导出；公开原生组件优先。
- MIT，Copyright © 2026 MJ-CJM。

已验证的 U2–U4 产品代码见[完整 UI 报告](../verification/ui-completion/README.md)。其 528 张页面矩阵与群专项属于摘要 `0203b5ea815c32d81f93c82408b41d959325a0ef78599e7418fa99c4a3241516` 的包，不能视作重新运行了新发布附件。发布包只调整包 README，产品代码与该包逐文件比较，并补充同包运行验收；具体结果在 Release notes 中填写。

真实模型质量、外部 IM 收发、系统/手机推送及持续主动运行不在已交付验收内。历史 0.3.2/0.4.0/0.4.1 原包缺失，旧包升级矩阵未执行；首次安装/同版本重装不替代历史迁移验证。完整宿主运行证据来自 macOS；Linux/macOS CI 是构建与自包含测试，不代表 Linux/Windows 桌面实跑。

## 发布操作

从最终主分支创建 v0.6.3，上传同一已验证 tgz、SHA256SUMS 与实际结果说明，再从公开链接下载复核。社区目录只提交本插件的 YAML，使用固定 tag 的下载地址。原始日志与私人 profile 保留在本地忽略目录，不上传。
