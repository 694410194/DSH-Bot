# U：Bot 展示与设置返回

用户已于 2026-11-01 批准[整体方案](../docs/design/group-concurrent-discussion-proposal.md)，并授权创建 Issue、Draft PR、必要提交与推送，优先实现本任务。

## 范围

- 提供固定的“我的 Bots / 群聊 / 最近对话”入口；Bot 全集不受最近对话隐藏状态影响。
- 设置明确原路返回，保留来源、选中对象、筛选、滚动与焦点；外部详情请求只消费一次。
- 群资料逐个展示成员身份和可用状态；查看成员能返回原群；归档为次要操作。
- 保留原生会话跳转、现有 Bot/group catalog、草稿与生命周期；不修改 Host 调度或引入新的宿主 API。
- 双语、主题与宽窄布局，补有意义的行为回归和隔离浏览器验证。

## 验收

1. 无会话/隐藏最近对话的 Bot 仍出现在我的 Bots。
2. 从三个一级入口、指定群详情进入设置后可回到原位置；刷新不抢页面。
3. 原群成员查看、未保存编辑、对象删除/代次改变及组件重挂载行为明确。
4. 导航不发送模型请求、不新建会话、不停止工作；原生显式聊天操作保留。
5. `scripts/pnpm check`、文档/格式检查、真实浏览器中英亮暗宽窄验证；CI 单列。

仅写本仓库，使用 `.dsh-dev` 隔离环境。不得修改正式桌面、`~/.dsh` 或运行真实模型。并发与执行过程属于后续 A–D 阶段。
